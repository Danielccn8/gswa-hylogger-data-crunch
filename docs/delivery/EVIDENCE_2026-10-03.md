# Local delivery evidence — 3 October 2026

This is an implementation record, not geological acceptance. Work is local on `codex/hylogger-system`, based on `14039dd`; no team branch was merged. The original checkout remains the acquisition source. The application is available at http://127.0.0.1:8000.

## What changed

- Added a shared reading contract for raw preparation, spectral intervals, processed intervals and the maintained TIR cleaner. Invalid depth, invalid spectra, missing/unknown masks and masked readings remain distinguishable. Repeated-depth measurements keep their identity. Numeric class codes cannot silently become mineral names.
- Added source snapshots. Narrower processed requests preserve the broader selected table. Snapshot paths sit near the data root to avoid Windows path-length failures.
- Added QC-versioned interval IDs, one explicit active interval set per hole/sensor, stored dashboard summaries, and exact-version profile/CSV queries. Historical rows remain available by ID.
- Changed similarity from centroid ordering to actual distance to the selected interval, across compatible assigned active sources. CSV exports reject over-limit requests rather than truncate silently.
- Added the selected analytical dashboard with Overview, Compare, Map, Data & method, shared filters, paginated interval detail and export. Leaflet is vendored with its licence; remote basemap failure does not remove the other views.
- Froze the target cohort and regional holdout in `configs/delivery_cohort.json`. Model fitting balances the total weight of each development hole. New holes use frozen inference and unseen features receive explicit rejection flags.

## Model evidence and limits

The two Goldfields groups supply 14 development holes. The six Eastern Pilbara/Paterson holes are held out together to examine regional transfer. This is a declared engineering split; historical team exploration means it cannot be claimed as independently blinded geological validation.

| Processed model | Version | k | Held-out silhouette | Mean ARI across three development seeds |
|---|---|---:|---:|---:|
| SWIR | `c5d1559555b3147f6882` | 3 | 0.18458 | 1.00000 |
| TIR | `3b49b3df3c030eafd3d9` | 4 | 0.35759 | 0.99956 |

All 2,133 diagnostic holdout intervals per sensor fit the feature schema. Silhouette measures separation in the selected representation, not mineralisation or geological accuracy. Equal hole training weights do not make neighbouring intervals independent. The dashboard's descriptive hole profiles remain useful independently of these cluster choices.

The revised spectral pilot fits **LD82625W1** and infers **WKDD15001**, using verified Final Mask rows. It retains five NIR PCA components (k=2) and six TIR components (k=3). Respectively **271/318** and **31/318** inference intervals exceed the training distance threshold. This is a training-coverage warning, not evidence that those intervals are erroneous or mineralised. The pilot remains separate from the processed interval models.

The raw NIR package spans 380–2500 nm, including VNIR and SWIR. It is not a SWIR-only spectrum. The TIR grid spans 6000–14500 nm. Full normalization/band-range selection and transfer evaluation are still needed before a wider raw model is promoted.

## Verification

- **59 automated tests passed**, including four database tests in disposable transaction-scoped schemas. They verify revision isolation, explicit historical access, true query-distance similarity across groups, CSV/model consistency and depth-range handling. Existing two-pattern fixtures emit expected K-Means convergence warnings when requesting three/four groups.
- Shared-QC regressions cover non-finite/negative/string-sentinel depths, spectral sentinels, repeated depths, absent masks, malformed wavelength grids and undecoded numeric classes. Narrow-fetch preservation is tested.
- Real raw verification checks original header depths, original Final Mask values and independently recomputed median spectra at beginning/middle/end intervals in both sensors of both holes. Counts reconcile: LD82625W1 96,560 received / 70,717 admitted; WKDD15001 46,572 / 34,258. This is sampled paired-row verification, not a CRC check of every archive member or a second human review.
- Live API checks compare selected interval IDs against CSV, independently recompute ten returned similarity distances per sensor and reconcile QC counts. Target20 has 20/20 products for each sensor.
- Browser acceptance exercises Overview, two-hole Compare, interval/similarity detail, filtered CSV, map markers, Method, empty search, sensor changes, mobile overflow and blocked external-basemap requests. Initial observed page load was 218 ms; this is one local observation, not a service-level guarantee.
