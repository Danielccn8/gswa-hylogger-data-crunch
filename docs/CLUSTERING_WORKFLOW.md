# Clustering workflow

## Pilot gate

Do not begin with every WA hole. Start with 10-20 reviewed holes covering multiple locations, operators, scan dates, processing levels, and HyLogger generations.

A pilot is ready when every hole has explicit processed/raw availability, log names and processing levels have been compared, spectral dimensions are recorded, QC is quantified, and features can be generated by `hylogger prepare` without notebook-specific cleaning.

## Reproducible experiment

1. Commit the selection YAML.
2. Run `hylogger prepare --selection <name>`.
3. Copy `configs/experiments/clustering_baseline.yaml`.
4. Run the baseline notebook with a fixed random seed.
5. Write generated outputs under `experiments/<experiment_id>/`.
6. Record metrics, assignments, feature names, package version, and selection.
7. Interpret clusters against geology and acquisition metadata.

## Feature principles

- Keep NIR/SWIR, TIR, and MIR namespaces separate.
- Do not treat TSG labels as ground truth.
- Compare automatic, user-refined, and domain-refined products explicitly.
- Exclude invalid labels from mineral proportions but preserve invalid-rate QC.
- Standardise continuous features inside the model pipeline.

The starter notebook is `notebooks/30_clustering/01_baseline_clustering.ipynb`.
