# HyLogger user guide

1. **Find data.** Open the map and choose a drill-hole marker, or enter an ID in **Drill-hole ID** and choose **Open profile**. Grey individual markers are catalogue only; blue has SWIR intervals, purple has SWIR and TIR. An orange outline flags unusable reported length. Marker-cluster circles show counts, not a mineral class. The catalogue snapshot has 1,897 holes; only 26 have loaded interval products.
2. **Read the depth profile.** Choose SWIR or TIR. Intervals increase downwards in metres; the coloured fill shows admitted/total readings and each row names the dominant TSG group and model group. Missing depth spans have no loaded readings; they are not zero mineral content. For LD82625W1, all 642 SWIR intervals are available in the scrollable profile.
3. **Inspect an interval.** Select a row. The detail gives the group and centroid distance. Open **How this was calculated** for dataset, source rows, reason counts, feature frequencies, mask availability and model ID. Open **How the groups were made** for the feature representation, k choice, held-out score and original-frequency profiles. The adjusted TSG spectral pilot is drawn where available (LD82625W1); elsewhere the page explains that no spectrum was prepared. A distance flag is not a geological anomaly.
4. **Find similar intervals.** The list ranks intervals in the same frozen model group by distance to their shared centroid. It may include other holes. It is an exploratory ranking, not a probability of shared geology.
5. **Export.** Use **Download displayed depth range as CSV**. It includes depths, QC counts, source rows, interval-set and selected model ID. Preserve those IDs with any figure or interpretation. Use the profile's current sensor and visible depth extent when comparing the download.
6. **Compare whole holes.** In **Compare the 20-hole cohort**, choose SWIR or TIR and select **Show hole comparison**. Each card is one hole with its whole-hole group, nearest other hole, diagnostic interval count and leading TSG group frequencies. **Open depth profile** returns to the underlying intervals. SWIR includes 20 holes; TIR includes 18 because 07THD003 and 09RTD001 have no compatible TIR interpretation in this batch. An orange review candidate is in the top 10% of nearest-neighbour distance for this cohort. It is an exploratory relative outlier flag, not a geological anomaly or prospectivity score. Expand **Method, evaluation and groups** to see candidate k, silhouette, two-seed stability, group profiles and limitations.

**Worked reading:** in 05GJD001 SWIR at 150–151 m, 56 of 169 readings contribute group frequencies; 113 are nondiagnostic. DARK-MICA is 62.5% of those 56 interpreted readings. The processed log does not provide Final Mask. Group 0 is an internal K-Means label, and distance 0.803 is not confidence. The exact source checksum and API/Parquet/DB identity are in `docs/PIPELINE_GUIDE.md`.

Empty and error states are explicit in the side panel: 07THD003 has no loaded TIR product, and a sensor without a frozen model keeps its intervals but says unassigned. **Processing status** separates total loaded products from the latest batch; `/api/system/runs` holds older batches and full errors. To inspect a model card, call `/api/system/models` or read generated `data/system/models/<region>/<model_id>/model_card.json`. For quality, use `data/system/etl/<interval_set_id>/qc.json` or the interval API response.

The whole-hole comparison is a separate generated artifact at `/api/system/comparisons/team-20/swir` and `/api/system/comparisons/team-20/tir`. Recreate both files with `.\.venv\Scripts\python.exe scripts/compare_20_holes.py` after the reviewed 20-hole ETL products are present. Starting Compose only serves existing artifacts; it does not run this analysis.

Browser acceptance was performed locally on 2026-09-25 for the map, full profile, model explanation, interval, similar ranking, spectral chart and CSV, including an empty TIR case. Saved screenshots and a human comprehension check remain pending; no team member or GSWA has signed off. Demo data must be acquired under its applicable licence; no client data is bundled here. The map's Leaflet scripts and public tiles currently require Internet access.
